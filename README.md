# Face Fit — виртуальная примерка одежды

Браузерное расширение (Manifest V3) для маркетплейсов: заменяет лицо модели на карточке
товара вашим собственным. **Вся обработка — локально в браузере**, ваше фото никогда не
покидает устройство.

Некоммерческий учебный проект. Распространяется только через GitHub — не публикуется
в Chrome Web Store (см. [«Модели и лицензии»](#модели-и-лицензии)).

## Что умеет

- Работает на **Lamoda**, **Wildberries**, **Ozon**.
- Наведение на заменённое фото показывает всплывающую кнопку — можно быстро вернуть
  оригинал и переключиться обратно.
- Настройка «только модели своего пола» (Ж/М) — можно и выключить, чтобы примерять
  образы любого пола.
- «Маска в лоб» — поднимает край замены в линию волос, стык менее заметен.
- Интерфейс на русском и английском (подстраивается под язык браузера).

## Установка

Расширение не проходит через Chrome Web Store, поэтому ставится вручную — это часто
называют «режимом разработчика». Это официальный, безопасный способ установки
расширений не из магазина, просто без автоматических обновлений. Шаги ниже — подробно,
с расчётом на то, что вы делаете это впервые.

### Шаг 1 — скачайте проект

Если пользуетесь git:

```bash
git clone https://github.com/<ваш-репозиторий>/face-fit-extension.git
cd face-fit-extension
```

Либо на странице проекта на GitHub: **Code → Download ZIP**, распаковать архив.

### Шаг 2 — соберите расширение

**2.1. Установите Node.js**, если его ещё нет на компьютере. Зайдите на
[nodejs.org](https://nodejs.org/), скачайте установщик версии **LTS** (она же самая
крупная зелёная кнопка на сайте) и запустите его — везде можно нажимать «Далее»
со значениями по умолчанию.

**2.2. Откройте терминал прямо внутри папки проекта** (той, что получилась после
шага 1 — там лежат файлы вроде `manifest.json`, `package.json`):

- Откройте эту папку в проводнике Windows.
- Кликните один раз в адресную строку проводника сверху (туда, где написан путь
  до папки), сотрите то, что там написано, наберите `cmd` и нажмите Enter.
- Откроется чёрное окно терминала — оно уже «смотрит» внутрь нужной папки, ничего
  дополнительно набирать не нужно.

*(Альтернатива на Windows 11: клик правой кнопкой мыши по пустому месту внутри
папки → «Открыть в терминале».)*

**2.3. Наберите команды по очереди.** В открывшемся чёрном окне впишите (или
скопируйте и вставьте правой кнопкой мыши — вставка через Ctrl+V в терминале
часто не работает) первую строку, нажмите Enter, дождитесь, пока команда
закончится и снова появится приглашение для ввода, и только тогда вводите
следующую:

```bash
npm install
npm run setup
npm run build
```

Что при этом происходит:

- `npm install` — скачивает служебные библиотеки для сборки. Минута-две.
- `npm run setup` — скачивает сами модели распознавания лиц (суммарно ~450 МБ).
  Работает **молча** несколько минут — если ничего не выводится и курсор просто
  мигает, это нормально, команда не зависла, наберитесь терпения.
- `npm run build` — собирает готовое расширение. Быстро, меньше минуты.

Когда все три команды отработали без красных строк с `Error`, в папке проекта
появится новая папка **`dist`** — это и есть готовое к установке расширение,
переходите к шагу 3.

### Шаг 3 — загрузите расширение в браузер

**Если у вас Google Chrome:**

1. Скопируйте и вставьте в адресную строку браузера, затем нажмите Enter:
   ```
   chrome://extensions/
   ```
2. Включите переключатель **«Режим разработчика»** (обычно в правом верхнем углу страницы).
3. Нажмите появившуюся кнопку **«Загрузить распакованное расширение»**.
4. В открывшемся диалоге выберите папку `dist` внутри проекта (не архив, а именно папку).

**Если у вас Яндекс Браузер:**

1. Скопируйте и вставьте в адресную строку, затем нажмите Enter:
   ```
   browser://extensions/
   ```
2. Включите переключатель **«Режим разработчика»** (справа сверху).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `dist`.

После этого в панели расширений браузера появится иконка Face Fit.

### Шаг 4 — настройка

Откройте popup расширения (клик по иконке) — там встроена короткая подсказка «Как
начать», но вкратце:

1. Загрузите своё фото анфас (лицо должно быть хорошо видно).
2. Откройте Lamoda, Wildberries или Ozon — прямые ссылки есть в самом popup.
3. Включите переключатель вверху popup.

Обновления: расширение не обновляется само (оно не из магазина). Чтобы получить новую
версию — скачайте свежий код и повторите шаги 2–3 (в браузере старую версию можно
предварительно удалить на той же странице `chrome://extensions/` / `browser://extensions/`,
либо просто загрузить поверх — Load unpacked обновит существующую).

## Приватность

- Ваше фото хранится только в IndexedDB на вашем устройстве и никогда никуда не
  отправляется — ни на какой сервер, включая наш собственный (у проекта его просто нет).
- Распознавание лиц и сам face swap считаются локально в браузере, на GPU через WebGPU
  (с откатом на CPU/wasm, если WebGPU недоступен).
- Все модели и библиотеки — часть пакета расширения, ничего не подгружается из сети
  в момент работы. Единственный сетевой трафик самого расширения — фотографии товаров,
  которые оно скачивает с CDN маркетплейса, чтобы было что заменять.
- Никакой аналитики, телеметрии или сбора статистики использования.
- Код открыт — можно проверить всё вручную.

## Модели и лицензии

Расширение использует сторонние модели компьютерного зрения, скачиваемые скриптом
`npm run setup` напрямую из первоисточника (они не входят в репозиторий и не
распространяются этим проектом):

- **MediaPipe Face Landmarker** (Google, Apache 2.0) — детекция лица и ключевых точек.
- **ArcFace** (`w600k_r50`, [InsightFace](https://github.com/deepinsight/insightface)) —
  распознавание лица.
- **inswapper_128** ([InsightFace](https://github.com/deepinsight/insightface)) — сама
  замена лица. Лицензия — **non-commercial research only**.

Именно из-за лицензии inswapper и общей чувствительности темы «замена лица» для
модерации магазинов приложений проект **сознательно не публикуется в Chrome Web
Store** — только как открытый исходный код на GitHub, для личного некоммерческого
использования.

## Известные ограничения

- Работает только на трёх площадках выше — на прочих сайтах расширение неактивно.
- Меняется только овал лица; причёска, форма головы и уши остаются от модели на фото.
- На фото с зеркальными/тёмными солнцезащитными очками изредка виден лёгкий цветной
  артефакт у виска — модель ландмарков хуже оценивает положение глаз, когда они полностью
  закрыты бликующими линзами.
- Нужен браузер на Chromium с поддержкой Manifest V3 (Chrome, Яндекс Браузер и т.п.).

## Разработка

```bash
npm test        # юнит-тесты (Vitest)
npm run dev     # сборка с hot-reload, тоже грузится как unpacked из dist/
npm run icons   # перегенерировать icons/icon*.png из icons/icon.svg
```

### Структура проекта

| Путь                             | Назначение                                                        |
| --------------------------------- | ------------------------------------------------------------------ |
| `manifest.json`                   | Манифест MV3 (permissions, host_permissions, CSP)                 |
| `vite.config.js`                  | Сборка расширения через CRXJS                                     |
| `scripts/prepare-assets.mjs`      | `npm run setup` — копирует wasm, качает модели                     |
| `scripts/postbuild.mjs`           | Чистит неиспользуемые файлы из `dist/` после сборки                |
| `scripts/gen-icons.mjs`           | Генерирует PNG-иконки из `icons/icon.svg`                          |
| `popup.html/css/js`               | UI popup: фото, настройки, онбординг, статус страницы              |
| `background.js`                   | Service worker — управляет offscreen-документом, роутинг сообщений |
| `content.js`                      | Сканирует страницы маркетплейсов, подменяет фото                   |
| `src/content/scanner.js`          | Чистая логика сканера (кандидаты в картинки, очередь, URL CDN)     |
| `src/content/badge.js`            | Всплывающий бейдж на заменённых фото (Shadow DOM)                  |
| `src/offscreen/offscreen.js`      | Offscreen-документ — весь конвейер face swap (WebGPU)              |
| `src/lib/faceLandmarker.js`       | Обёртка MediaPipe (GPU→CPU fallback, ключевые точки, детекция)     |
| `src/lib/ort.js`                  | Обёртка ONNX Runtime Web (WebGPU → wasm)                           |
| `src/lib/align.js`                | Выравнивание лица по 5 точкам, кроп через canvas                   |
| `src/lib/arcface.js`              | ArcFace: кроп 112 → эмбеддинг 512                                  |
| `src/lib/inswapper.js`            | inswapper: кроп 128 + эмбеддинг → лицо с новой личностью           |
| `src/lib/genderage.js`            | Классификация пола/возраста цели (для настройки «только свой пол») |
| `src/lib/blend.js`                | Вклейка лица обратно: маска по контуру, растушёвка, подгон цвета   |
| `src/lib/storage.js`              | Фото → IndexedDB, метаданные → `chrome.storage.local`               |
| `src/lib/assetUrl.js`             | URL до файла внутри пакета расширения                              |
| `_locales/{ru,en}/messages.json`  | Переводы интерфейса (`chrome.i18n`)                                |
| `src/test/*.html/js`              | Отладочные стенды для разработки (детекция, face swap, offscreen)  |
| `public/wasm`, `public/ort`, `public/models` | Локальные ассеты, генерируются `npm run setup` (не в git) |
| `icons/`                          | Исходная SVG-иконка + сгенерированные PNG                          |
